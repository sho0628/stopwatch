# ストップウォッチ・マジック

iPhone標準のストップウォッチそっくりのWEBアプリ。
お客さんに渡して好きなところ（5秒近辺など）で止めてもらっても、
**事前に演者が仕込んだ秒数が表示される**マジック用アプリです。

## 仕組み

- 見た目・操作は本物のiPhoneストップウォッチと同じ（スタート／ストップ／ラップ／リセット）。
- 「アーム（仕込み）」していなければ**本物の時計として正確に動作**するので、お客さんに検めてもらえます。
- アーム状態のときは、**いつストップしても表示が仕込んだ数字にスナップ**します。

## 使い方

### 1. 公開する
`index.html` をWEBに置くだけ（GitHub Pages 等）。
iPhoneのSafariで開き、共有 →「ホーム画面に追加」すると、
アドレスバーのない全画面で本物そっくりに表示できます。

### 2. 数字を仕込む（演者・秘密）
1. 大きな数字（タイマー表示）を **約0.7秒 長押し** すると、仕込みパネルが開きます。
2. テンキーで秒数を入力します。数字は **右から `MM:SS.CC`（分:秒.1/100秒）** の順に詰まります。
   - 例：`583` と押す → `00:05.83`
   - 例：`12345` と押す → `01:23.45`
3. **「セット（仕込む）」** を押すとアーム完了。パネルが閉じます。
4. アーム中はタイマーの **「.」がうっすら緑色** になります（演者だけが分かる目印）。

### 3. 演じる
1. リセットして `00:00.00` の状態でお客さんに渡します。
2. お客さんが「スタート」→ 数字が普通に上がっていく → 5秒近辺で「ストップ」。
3. 表示が **仕込んだ数字** で固定されます。

### 通常の時計に戻す
仕込みパネルを開いて **「通常モード」** を押すとアーム解除（緑の「.」が消える）。
以降は本物のストップウォッチとして動きます。

## ヒント
- 仕込む数字は、お客さんが止めそうな時間（5秒近辺）に合わせると自然です。
- お客さんに渡す前に必ずリセットしておくこと。
- 検めさせたいときは「通常モード」にしておけば、ごく普通の正確なストップウォッチです。
